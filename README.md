# 💻 Laptop Data Analysis (Excel Dashboard)

## 📌 Overview

This project analyzes laptop dataset using Microsoft Excel.
It includes data cleaning, pivot tables, and an interactive dashboard.

## 📊 Features

* Brand Distribution Analysis
* Processor Comparison
* RAM & Storage Insights
* GPU Analysis
* Brand-wise Price Comparison

## 🛠 Tools Used

* Microsoft Excel
* Pivot Tables
* Charts (Bar, Pie, Line)
* Slicers

## 📈 Key Insights

* Intel i5 & i7 processors are most used
* SSD storage is more popular than HDD
* 16GB and 32GB RAM laptops are trending
* Price varies by brand significantly
